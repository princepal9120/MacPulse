# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use the
repository's private security advisory flow on GitHub, or contact the
maintainer through the email listed on the GitHub profile.

Include reproduction steps, affected version, impact, and a minimal proof of
concept. Redact usernames, paths, tokens, and other personal data.

## Safety principles

MacPulse is local-first and does not intentionally collect telemetry. Cleanup
operations are confirmation-gated and use recoverable Trash moves where the
platform permits. Full Disk Access should only be granted to a build you trust.
